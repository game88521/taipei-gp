# 台北街道賽 Taipei Street GP

手機瀏覽器就能玩的**真實台北東區**（約 7 × 5.3 公里：西到大安森林公園、東到南港邊、北到基隆河、南到象山）：
- **自由駕駛**：開一般汽車在開放的街道上隨便開，有車流、紅綠燈、行人、路名牌、地標與小地圖；
  開到橘色光柱停下來可以接受**街頭飆車**挑戰（市府衝 101、國父紀念館 → 國際會議中心、信義百貨巡禮）
- **車庫**（自由駕駛、計程車都適用）：7 台車都可以免費選（main.ts 的 FREE_CARS 改 false 就變回賺錢買：發財車 600、巡邏車 1,500、紫電 GT 2,500、
  雷霆 V12 4,500、躍馬紅 F1 8,000）；每台 10 種烤漆（每色 300）。錢來自計程車車資、正賽名次獎金、街頭比賽獎金。
  每台的加速、極速、煞車、抓地力、重量、引擎聲都不一樣，越重的車撞車流撞得越遠。開別台車載客時車頂會加 TAXI 燈箱。街頭比賽一律開 F1（對手強度照它調）
- **🚨 警察追逐**：撞車流、撞到行人、闖紅燈、撞警車會被通緝（最多 5 星），警車照路網追捕；被逼停 3 秒＝逮捕罰款、離警車夠遠撐 12 秒＝甩掉。
  開巡邏車按「🚨 追緝」（電腦 G）可以反過來追嫌犯車，撞停就有獎金
- **車流會反應**：撞飛的車會再撞別台（連環車禍）、機車會倒；按喇叭（電腦 H、手機 📯）前車會換車道讓路或回按；擋住車流太久後車會按喇叭
- **時段天氣**（選單）：黃昏、白天、夜晚、雨天、雨夜、自動日夜循環（約 13.5 分鐘一圈，左上有時鐘）；夜晚有路燈光圈、車頭燈、車流頭尾燈，
  101 亮翠綠燈與跑馬燈，招牌更亮；雨天有雨絲與會反光的濕路面
- **車內視角**（📷／電腦 C）：儀表板、A 柱、方向盤（F1 是 Halo），下雨時擋風玻璃有雨滴和雨刷
- **車損**：撞擊累積，烤漆變髒、頭燈破、引擎冒煙、火花，嚴重時跑不快；停車時可以修車
- **大地圖與導航**（🗺／電腦 M）：全螢幕地圖點目的地或選地標，路上箭頭指路
- **城市更活**：文湖線列車在高架上跑；行人看到車衝過來會尖叫跑開、按喇叭會回頭看；車流會打方向燈轉彎、換車道超車
- **成就與紀錄**（選單）：14 個成就與各項統計
- **線上排行榜**（選單）：計時賽最快圈自動上傳（需要在 Vercel 開啟儲存空間，見下方）
- **🚕 計程車載客**：開小黃到綠色光柱載客，限時送到地標；照台北跳表（起跳 85、每 200 m 5 元）收車資，提早到有小費、撞車扣小費，收入會累積
- **街頭對決**：選一條路線（5 條），在開放街道上跟 4 台 AI 同時出發，有車流與紅綠燈、即時名次
- **街道賽：對決 7 台 AI**：封路的 F1 正賽（3 或 6 圈），發車格起跑、尾流、超車、DRS、輪胎磨耗與進站、即時名次、成績表與完賽回放
- **計時賽**：同一條賽道一個人跑，有影子車
- 賽道：信義路 → 基隆路 → 忠孝東路 → 松仁路，一圈 3.1 km，起跑線在 101 前

Vite + TypeScript + Three.js；道路、近 2 萬棟建築、紅綠燈、斑馬線、路名來自 OpenStreetMap，貼圖、車子、音效全部用程式產生，沒有素材檔。
象山、四獸山有地形（爬不上去的坡會擋車）；地圖外圍再補一圈約 900 m 的遠景城市，地平線有一圈遠山。
地標有自己的造型：國父紀念館（黃琉璃瓦飛簷）、大巨蛋／小巨蛋、市政府、松菸紅磚廠房、台北機廠煙囪、象山步道與六巨石；
另有建國高架、市民大道高架、基隆路高架、信義區人行空橋、捷運文湖線高架（車子從底下過，橋墩會擋）。
基隆河與公園池塘有會反光的水面（開不進去）；饒河街觀光夜市兩側有攤位、燈箱與紅燈籠。

## 跑起來

```
npm install
npm run dev          # 會印出 Network 網址，手機連同一個 Wi-Fi 開那個網址
npm run build        # 輸出到 dist/，推上 GitHub 後 Vercel 會自動部署
npm run check-track  # 賽道健檢：長度、最急彎、路段是否靠太近
```

## 地圖資料流程（只有要改路線或更新地圖時才需要）

```
node tools/fetch-rail.mjs  # 另外下載捷運軌道（文湖線高架）→ tools/osm-rail.json（不進 git，沒有也能 build）
npm run fetch-osm    # 從 Overpass API 分塊下載（原本 6 塊＋北側、西側擴充長條＋水域）（快取在 tools/osm-cache/，失敗重跑會跳過已下載的）→ tools/osm-raw.json（23 MB，不進 git）
npm run build-city   # 轉成 src/data/track.json（賽道）、public/data/city.json（路網、綠地、地形…）與 public/data/tiles/（建築、樹、路邊機車，600 m 一塊）
npm run plan         # 輸出 tools/plan.svg 平面圖，檢查賽道有沒有對準真實道路
```

`tools/build-city.mjs` 的重點：
- **賽道**：每一邊取那條路「行車方向正確」的車道，每 8 m 平均成一條線；路口直角修成半徑 24 m 的圓弧，再往中央分隔島平移 2.5 m。
  基隆路往北過了松壽路之後主車道進了車行地下道，所以直接取道路的平面走向，不照實際的地下道／單行規定找路。
- **建築**：輪廓 + 高度（`height`，沒有就用樓層數 × 3.3 m）；有 `building:part` 的建築改畫各部件。
  壓到賽道的建築會刪掉。101 的塔身在 `src/city.ts` 用竹節造型重做（OSM 只有一根方柱），裙樓照 OSM。
- **行道樹**：OSM 有標的樹 + 主要道路兩側每 11 m 一棵 + 公園、森林裡隨機撒 + 山坡上補種。
- **區塊**：最後呼叫 `tools/split-tiles.mjs`，把建築、行道樹、路邊機車依 600 m 切到 `public/data/tiles/{tx}_{tz}.json`（目前 138 塊），
  核心 city.json 只剩全地圖都要用的東西（車流、導航、小地圖要整張路網）。也可以對還沒切過的 city.json 單獨執行 `node tools/split-tiles.mjs`。
- **地形**：`PEAKS` 列出象山、拇指山、虎山、豹山與南側稜線；在森林或山頭核心範圍、離道路／建築／賽道夠遠的格點才隆起，邊緣模糊成緩坡。

## 線上排行榜（Vercel）

`api/leaderboard.js` 是 Vercel Serverless Function，資料存在 Upstash Redis：
Vercel 專案 → Storage → Create / Connect → **Upstash for Redis**（免費方案）→ Connect 到這個專案，
會自動加上 `KV_REST_API_URL`／`KV_REST_API_TOKEN`（或 `UPSTASH_REDIS_REST_URL`／`UPSTASH_REDIS_REST_TOKEN`）環境變數，重新部署後就會啟用。
沒設定時 API 回 503，遊戲裡顯示「排行榜尚未啟用」。每個車手名字只留最快一圈；圈速要在 40~300 秒之間、同一個 IP 10 秒只能上傳一次。

## 離線快取（Service Worker）

`npm run build` 會自動產生 `dist/sw.js`（範本在 `src/sw-template.js`，產生邏輯在 `vite.config.ts`），核心街景資料也會一起快取（城市區塊檔是開到附近才抓、抓過的才快取）。
玩過一次之後第二次開幾乎瞬間載入，沒網路也能玩；任何檔案改了版本號就會變，手機下次開啟自動換新版。
`npm run dev` 時不會註冊，避免改了程式碼看不到。

## 城市串流

建築、頂樓、路邊機車、行道樹依 600 m 區塊串流（`src/city.ts` 的 `stream`）：只載入鏡頭周圍「可視距離 + 一個區塊」內的區塊，
開遠了在背景載入前方的（每格畫面最多花 6 ms 蓋，身邊的區塊還沒好時 25 ms），超出範圍 450 m 就卸掉（網格、碰撞、可撞倒的樹一起拿掉）。
地圖再大，同時在記憶體裡的量也只跟可視距離有關：目前的地圖高畫質載 51／138 塊，JS 記憶體約 170 MB（全部載入是 320 MB）。
所有區塊共用同一組材質，載入時在場景裡各放一個隱藏的代表，讓天氣系統收集得到、著色器先編好。
自動測試（`?sim=`）與 `?alltiles` 一次載入全部區塊、不卸載（同步模擬等不到背景載入）。
區塊檔不列入 Service Worker 的預先快取，開到附近才抓、抓過的存進快取。

## 畫質

選單可選「自動／高／中／低」（改了會重新載入）。自動：手機用中、電腦用高，開局 6 秒內平均低於 32 fps 會自動降一級並記住。
選單也可以打開 FPS 顯示。測試時可用 `?q=medium` 直接指定等級。

| 等級 | 車子即時陰影 | 光暈 | 車流／行人 | 可視距離 | 路邊機車、頂樓水塔 |
|---|---|---|---|---|---|
| 高 | 2048 | 全解析度 | 90／130 | 1900 m | 有 |
| 中 | 1024 | 半解析度 | 55／70 | 1450 m | 有 |
| 低 | 無 | 無 | 35／40 | 1000 m | 無 |

光影大多是**預先算好的**（不吃效能）：建築的地面影子（沿太陽方向拉長的凸包）、樹影、牆腳的接地陰影，用 stencil 讓重疊的影子不會疊得更黑；
只有車子會即時投影。

依距離分層顯示（`city.ts` 的 `cull`）：外牆、屋頂 600 m 一塊，整個可視距離都畫；樹冠畫到 6 成；店面、招牌、地上影子、路邊機車、樹幹只畫 550 m 內；
路名牌只畫 300 m 內。大地圖每格約 360 次繪製（沒分層前 1300 次）。

## 操作

- 自由駕駛（手機橫向）：左下 ◀ ▶ 轉向，右下油門／煞車（停住再按煞車＝倒車），右上「⟲」卡住時移回道路
- 街道賽（手機橫向）：左下 ◀ ▶ 轉向、右下按住煞車，油門自動；DRS、進站在煞車上方
- 手機轉向可在選單改：左右按鈕（預設）／拖曳滑桿／傾斜手機（陀螺儀）。觸控按鈕在偵測到觸控螢幕或第一次被手指點到時就會出現
- 電腦：↑ / W 油門、↓ / S 煞車／倒車、← → / A D 轉向，Ctrl 或 E 開 DRS、B 進站，Esc 暫停
- 選單可開關：行車輔助線、影子車、音效、FPS 顯示
- 撞車流：照質量交換動量，被撞的車會被撞出去、旋轉、滑行（撞牆會停），幾秒後開回車道；機車被撞夠大力會倒地，公車幾乎撞不動

## 測試網址參數

- `?bot`：自動駕駛（照建議速度開）
- `?bot&sim=60`：街景載入後直接模擬 60 秒，圈速寫在分頁標題，給無頭瀏覽器測用
- `?phys`：汽車物理測試（0→100、時速 60／120 迴轉半徑、朝最近的牆直衝後倒車與轉向能否脫困、時速 60 撞停著的轎車／機車／公車、直衝撞倒東西），結果在標題
- `?free`：直接進自由駕駛；`?free&bot&sim=N` 油門全開直行 N 秒（測碰撞），`?free&bot&idle&sim=N` 停在原地讓車流跑 N 秒，標題印出車流與行人統計
- `?bot&gp&sim=260`：自動駕駛跑 3 圈正賽，標題印出名次與各車完賽時間
- `?free&bot&sr=0&sim=200`：自動接受第 0 個街頭飆車挑戰並照路線開；加 `&notraffic` 關掉車流只測路線與檢查點
- `?bot&gp&solo&sim=130`：只讓第一台 AI 自己跑，量它的圈速與撞牆次數（`&g=` 抓地力比例、`&b=` 煞車減速度、`&line=` 賽車線幅度、`&lm=` 離路緣距離可覆寫）
- `?free&bot&sr=0&ram&notraffic&sim=12`：測撞擊，標題印出對手被撞離路線的最大距離
- `?free&bot&taxi&sim=N`：自動跑計程車任務，標題印出趟數與收入
- `?bot&gp&laps=6&sim=520`：6 圈正賽；`&replay=40&cam2=tv|chase|heli` 跑完直接停在回放第 40 秒
- `?prof`：標題印出載入各階段耗時（ms）
- `&time=night`：直接指定時段天氣（dusk／day／night／rain／rainnight）
- `?free&bot&idle&wanted=2&sim=45`：一開始 2 星通緝、原地不動，看警車多久逮到人；`?free&bot&car=police&pursuit&sim=150` 測追緝嫌犯
- `?free&bot&idle&honktest&sim=30`：測喇叭（讓路台數、車流按喇叭次數）
- `&view=cockpit`：車內視角；`&dmg=0.8`：一開始就有車損；`&time=auto&cyclet=520`：日夜循環跳到第 520 秒；`&trainfreeze`：文湖線列車停住
- `&car=muscle`：直接指定車（sedan／taxi／muscle／f1／super／police／pickup）；`&view=front` 鏡頭從左前方看車（檢查外型）
- `&cam=x,y,z,lx,ly,lz`：固定鏡頭位置與看的點（截圖檢查街景用），例如 `?bot&sim=1&cam=560,4,520,263,200,393` 從信義路看 101

## 程式結構

| 檔案 | 內容 |
|---|---|
| `src/track.ts` | 讀賽道、取樣、曲率、建議速度曲線、車子性能常數 |
| `src/world.ts` | 賽道路面、路緣、護牆看板、起點門架、路燈、天空、遠山、光線與預先算好的影子材質 |
| `src/city.ts` | 真實街景：建築外牆（公寓／玻璃帷幕／公家）、店面、直式招牌、綠地、行道樹、地形、101、依距離分層顯示 |
| `src/filler.ts` | 地圖外圍的遠景城市（方塊＋著色器畫的窗戶，5 次繪製，有碰撞） |
| `src/decor.ts` | 有標線的路面、斑馬線、路口綠色路名牌、地標屋頂招牌 |
| `src/citydata.ts` | city.json／區塊檔的型別與解碼、路網查詢（最近路名）、建築碰撞（可依區塊增減） |
| `src/freecar.ts` | 自由駕駛的汽車物理（油門、煞車、倒車、碰撞） |
| `src/traffic.ts` | 車流（IDM 跟車、路口轉彎）與紅綠燈（號誌路口分群、週期、燈號顯示） |
| `src/breakables.ts` | 撞得倒的東西：行道樹、路燈、號誌桿、路名牌（倒下動畫、車子只減速不卡住、開遠後復原） |
| `src/router.ts` | 導航：照路網（含單行）找最短路線並平滑 |
| `src/taxi.ts` | 計程車任務（載客點、時限、跳表、小費） |
| `src/peds.ts` | 行人（人行道來回走、斑馬線過馬路、等紅燈、閃避車子） |
| `src/quality.ts` | 畫質等級表 |
| `src/minimap.ts` | 隨車頭旋轉的小地圖（含飆車路線、檢查點、對手、挑戰點） |
| `src/models.ts` | 車輛（轎車、掀背、計程車、公車、機車＋騎士、肌肉跑車、超跑、警車、發財車）與行人各部位的外型 |
