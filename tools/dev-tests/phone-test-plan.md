# 手機實測清單（台北街道賽，線上版）

網址：https://taipei-gp.vercel.app/
這一版含的變更：夜間頭燈光斑拉長、夜間賽道邊線與紅白路緣發光、大獎賽進站的人形維修人員與換胎工具、計程車導航箭頭與大地圖路線、傾斜轉向的反轉與校正、存檔賽道版本、成就獎金。

## 先做一件事：確認是新版
1. 第一次開，或是之前已經裝到主畫面的話，關掉再開一次。
2. 如果選單右側（電腦）或最下面（手機）出現「有新版本 · 點此更新」，點它。這代表手機還在看舊版。
3. 更新完之後，確認進遊戲的時候畫面是新版（夜景的頭燈光會比較長）。

## 測試 A：夜間賽道（約 3 分鐘）
1. 選單 → 設定（左側導覽）→ 時段天氣 → 選「夜晚」。回到選單。
2. 選單 → 大獎賽。進到選賽道頁：上面是目前的賽道（台北），直接按「▶ 開始大獎賽」；要換成新加坡等夜賽，就在下面的賽道列表點一條，再按開始（左上角有「‹ 返回」）。等倒數結束開始跑。
3. 跑一圈，留意：
   - 前方路面的頭燈光是不是看得比較遠（大約 30 公尺）？
   - 白色邊線跟路緣在夜裡有沒有分得出來？
   - 彎道的紅白路緣有沒有亮？
4. 回報：
   - 「夜裡看得清楚嗎」：清楚／還是暗／看不出來的地方在哪？
   - 有沒有卡頓？卡的話大概在哪裡（直路、彎道、有很多車的地方）？

## 測試 B：進站換胎（約 3 分鐘）
1. 接續測試 A，在大獎賽裡跑。畫面右下角有「進站」按鈕，按下去之後，下一次經過進站口就會自動進站；按鈕會變金黃色、字變成「進站 ✓」，代表已排隊。
   - 手機沒有鍵盤，就直接按按鈕；電腦可以按 B。
2. 車子經過進站口時會自動轉進維修區，停進自己的格子，看到維修人員做完就好，不用管。
3. 回報：
   - 維修人員有手有腳嗎？看起來像不像在換胎？
   - 進站的時候順不順？有沒有突然卡住？
   - 停站結束後，畫面有沒有跳？

## 測試 C：計程車（約 2 分鐘，選做）
1. 選單 → 計程車載客。按下去直接進遊戲，不用再按開始。
2. 回報：路上有沒有出現導航箭頭？大地圖（🗺 按鈕）有沒有畫出路線？

## 測試 D：傾斜轉向（只有有陀螺儀的手機，約 2 分鐘，選做）
1. 設定 → 手機轉向 → 選「傾斜手機（陀螺儀）」。會出現「傾斜方向反過來」、「傾斜死區」、「用現在的角度當直走」三個設定。
2. 手機橫放、直走的時候，按一次「用現在的角度當直走」。
3. 左右傾斜，看車子轉向的方向對不對。
4. 回報：方向對嗎？如果相反，勾「傾斜方向反過來」再試。

## 回報格式（照這個寫就很好用）
```
機型：（例如 iPhone 14、Pixel 7）
瀏覽器：（Safari／Chrome）
A 夜間：清楚／還是暗；卡頓：無／在 ___
B 進站：維修人員像不像；順不順；畫面跳不跳
C 計程車：箭頭有沒有；大地圖有沒有路線（選做）
D 傾斜：方向對不對（選做）
其他：
```

## 如果要顯示 FPS
設定 → 勾「顯示 FPS」，數字在畫面左下角（綠字）。卡的時候照樣記下那一刻的數字就好。
