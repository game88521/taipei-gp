# Expedition 實機驗收（最後執行，尚未驗證）

先完成本機自動驗證；只測本機／另行授權的測試部署。不要使用正式站當測試環境。桌面 viewport、虛擬時間及鍵盤自動化不算本表的通過證據。

記錄手機型號、OS／瀏覽器、畫面方向、畫質、幀率上限、兩端網路，以及對應 build。沿用目前控制台設定不等於已發布本輪前後端。

1. 手機直式、橫式與瀏覽器工具列伸縮：HUD可拖曳／取消／保存，重新開啟仍保留手機設定，踏板和方向盤操作正常。
2. 兩台實體裝置進同一巡航房：同步起跑、共用晴／雨／夜、集合標記、換車與離房。切背景、鎖屏及斷網都應停止油門；續接不產生第二席。
3. 警匪：先確認雙方角色，再檢查起跑保護、不同高度不能攔截、連續近距離慢速才累積攔截、逾時／離線／完成的勝負文字正確。
4. 追走：兩段輪換領跑／追走，適當距離與角度才加分，碰撞中斷連段；兩端看到同一結果。
5. 救援：司機駕駛與停靠；協助者長按警示、側修／收放絞盤；司機固定、返程、卸載。兩端共用一輛車，切背景立刻停止操控，15秒內手動續接原席。
6. 定速拉力：完成原本城市全路線，按四個計時點比較早／晚到與超速；重設不記成績。退出還原原車、導航與天候。
7. 正式賽規：全場真人依正常道路駕駛，核對界線警告、VSC進度超車與最後調整排名；不要以明示位置 fixture 代替實際試駕。
8. 每日挑戰與教練：同日兩裝置得到同地圖／條件；返回頁面與跨午夜換題；不同規則的 PB 遙測不混用。
9. 在效能工具開始採樣後，城市與賽道各駕駛至少30分鐘，記錄長幀、貼圖／幾何數是否持續成長、畫質恢復及機身發熱。下載兩端報告，單次 FPS 不能當成改善百分比。
10. 兩支實體手把各測一次轉向、油門、煞車、返回選單及斷線；補足目前只有桌面鍵盤／畫面尺寸模擬的限制。

任一失敗需記錄步驟、兩端 build、房間玩法及本機報告。請勿在共享截圖或紀錄中貼續接 token。
